SYNTHETIC DATA -- NOT REAL PATIENT RECORDS
==========================================

The file `nsclc_dx_1st_seq_OS.csv` in this directory contains 200 entirely
synthetic patient records, generated by `demo/make_demo_cohort.py` from a simple
parametric survival model with a fixed random seed.

It contains NO real patient data of any kind. It is not derived from MSK-CHORD,
nor from any other clinical dataset. Patient identifiers are of the form
SYNTH-0001 to make this obvious at a glance.

The feature distributions are loosely modelled on non-small cell lung cancer so
that the generated clinical vignettes read plausibly, but they are invented and
should not be interpreted as epidemiological estimates. Results obtained on this
cohort do not correspond to, approximate, or validate any result reported in the
manuscript.

This data exists for one purpose: to let anyone run the Survprompt code paths
end to end without access to controlled clinical data.

Real MSK-CHORD data access is managed by the dataset provider:
https://datacatalog.mskcc.org/dataset/11458
